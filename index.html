Questions

The short version.

What is MCP?+

The Model Context Protocol is an open standard for how AI agents call external tools. An MCP server exposes your API as a set of tools an agent can discover and use directly. Portal generates one from your spec — no framework, no dependencies.

Do I have to change my API?+

No. Portal reads your existing OpenAPI spec and builds a separate interface layer on top. Your API stays exactly as it is.

Are my keys safe?+

Portal never asks for your API keys. The generated server reads a token from its own environment at run time, on your machine. Nothing is sent anywhere.

What does it cost?+

The generator is free and runs entirely in your browser. The optional live agent playground uses your own model key if you add one; otherwise it runs on mocked data.

Is the generated code mine?+

Yes. The MCP server is plain, dependency-free code you own and can read top to bottom. Run it, edit it, ship it — it's yours.
