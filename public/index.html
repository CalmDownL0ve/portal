The problem

Software was built for people who click. Agents don't click.

Built for clicks, not calls

Docs for people, not machines

No way in without a human

FAQ

Questions

What is MCP?

The Model Context Protocol — the emerging standard for how AI agents discover and call tools. Portal generates a server that speaks it, so any MCP-capable agent (Claude, and a growing list of others) can use your API directly.

Do I have to change my API?

No. Portal wraps your existing endpoints. The generated server calls your real API; you don't rewrite anything.

Are my keys safe?

Yes. In the hosted playground the key stays server-side and is never sent to the browser. The MCP server you download reads a token from its own environment. Portal doesn't store your keys.

What does it cost?

Converting your spec is free. Managed hosting with programmatic keys and usage metering will be usage-based when it launches.

Is the generated code mine?

Yes — the servers are zero-dependency, readable, and yours to run anywhere. Nothing locks you in.
